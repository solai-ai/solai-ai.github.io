Roadmap

Build real infrastructure first. Let the token become useful because the network is useful.

The roadmap follows progressive decentralization: start with local AI and provider infrastructure, then expand toward marketplace settlement, clusters, fault tolerance and autonomous agents.

Phase 0

Research

Architecture, economics, threat model, model strategy and protocol design.

Phase 1

Local AI

CLI, Ollama integration, local chat and model management.

Phase 2

Provider Runtime

Hardware detection, model detection, provider enablement, pricing, scheduling and heartbeat.

Phase 3

Marketplace

Provider discovery, filters, pricing, availability and reputation.

Phase 4

Solana Protocol

Token, staking, registry, lease, escrow and settlement programs.

Phase 5

Compute Rentals

End-to-end rental lifecycle with active leases and provider payments.

Phase 6

SOLAI Coder

Planning, decomposition, provider selection, model selection and budget management.

Phase 7

Task Clusters

Parallel jobs, sequential jobs, task graphs, dynamic workers and cluster budgets.

Phase 8

Fault Tolerance

Retries, provider replacement, replication and stronger verification layers.

Phase 9

Autonomous AI

Agents select models, purchase compute, construct clusters, execute tasks and validate results within spending limits.
